**Nome:** Nicollas Nogueira

**Disciplina:** Programação de Soluções Computacionais

13 exercícios do material de desvio condicional (if/else). Cada arquivo contém um programa independente, com entrada pelo teclado.

## Como executar

Com Java 11 ou superior, abra o terminal nesta pasta e execute, por exemplo:

```bash
java Exercicio01.java
```

Troque o número para executar os outros exercícios. Nos números decimais, utilize ponto: `1.75`, por exemplo.

| Arquivo | Exercício |
| --- | --- |
| Exercicio01.java | Metade de um número maior que 20 |
| Exercicio02.java | Maior ou menor de idade |
| Exercicio03.java | Igualdade ou diferença entre inteiros |
| Exercicio04.java | Dois números em ordem decrescente |
| Exercicio05.java | Intervalo de 50 a 100 |
| Exercicio06.java | Peso ideal conforme altura e sexo |
| Exercicio07.java | Bônus por tempo de empresa |
| Exercicio08.java | Validação da senha |
| Exercicio09.java | Prestação de até 30% do salário |
| Exercicio10.java | Maior de três números |
| Exercicio11.java | Categoria do nadador |
| Exercicio12.java | Desconto conforme a tabela do exercício |
| Exercicio13.java | Calculadora com if/else |

No exercício 12, a última faixa da tabela foi interpretada como salário acima de R$ 2.000,00, com desconto de 30%, completando as faixas anteriores. As porcentagens são as fornecidas na atividade.
